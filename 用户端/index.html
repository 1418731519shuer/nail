Data Model

门店试戴数据设计

这页把登录 ID、业务表、埋点触发、指标公式和搜索索引放在一起，方便后续接真实数据库、后台看板和推荐系统。

当前记录 ID --

首次进入生成匿名用户，登录后绑定微信或手机号，试戴、意向、订单、AI 对话都归到同一个 user_id。

Database Tables

数据库分层

身份与门店

  • stores门店基础信息，所有数据按 store_id 隔离。
  • users顾客主 ID，匿名用户和登录用户都落这里。
  • user_identities绑定微信 openid、unionid、手机号或匿名 device_id。
  • user_sessions进入、离开、停留时长、入口页面。

款式与素材

  • nail_styles款式名称、介绍、价格、主图、搜索文本。
  • style_tags冰透、渐变、猫眼、显白、通勤等标签字典。
  • nail_style_tags款式与一级、二级、扩展标签的关系。
  • style_images封面图、详情图、豆包参考图。
  • uploaded_assets用户手图、上传款式图、生成结果图。

试戴与成交

  • try_on_jobs每生成一次试戴写一行，是核心统计表。
  • batch_try_on_jobs一键试戴批量任务和进度。
  • style_exposures款式卡片进入视口后的曝光记录。
  • style_intents收藏、想做、预约、订单意向。
  • orders成交订单，区分 ai_try_on、walk_in、manual 来源。

画像与看板

  • event_logs所有原始埋点，方便回放和排查。
  • user_tag_scores用户偏好标签分数，做个性化推荐。
  • store_tag_scores门店偏好画像，指导上新和排序。
  • style_daily_stats款式每日曝光、试戴、意向、成交。
  • store_daily_stats门店每日活跃、试戴人数、平均停留。

Recommendation Logic

推荐系统分层

爆款高试戴 + 高意向率，首页和推荐位优先展示。
引流款高试戴 + 低意向率，适合吸引点击，但需要优化图、价格或详情。
潜力款低试戴 + 高意向率，增加曝光，放到推荐页或运营位测试。
弱势款低试戴 + 低意向率，降低权重或下架观察。

Event Flow

触发写入

  1. 打开页面创建或读取 user_id，开启 user_sessions。
  2. 款式曝光写 style_exposures，同 session 同款 5 分钟去重；曝光参与点击率和冷门款激活率。
  3. 点击试戴创建 try_on_jobs running；生成成功后计入试戴次数和人均试戴次数。
  4. 生成成功写 uploaded_assets，更新 try_on_jobs succeeded，并给款式标签加试戴权重。
  5. 设为意向写 style_intents，更新意向率、冷门款激活率和偏好标签。
  6. 成交完成写 orders，更新 AOV、AI AOV、主推款命中率。
  7. 每日聚合定时刷新 store_daily_stats 和 style_daily_stats，供运营日报和商家选品看板读取。
