# 美甲AI试戴小程序

美团校园AI Hackathon参赛项目 - 美甲AI试戴与智能运营

## 项目结构

```
nail-admin/
├── 运营端/          # 商家管理后台（Web端）
│   ├── src/
│   │   ├── views/
│   │   │   ├── dashboard/      # 运营日报
│   │   │   ├── trending/       # 爆款库管理
│   │   │   ├── styles/         # 款式管理
│   │   │   ├── recommend/      # 推荐位管理
│   │   │   └── ai-assistant/   # AI运营助手
│   │   ├── mock/               # Mock数据
│   │   └── router/             # 路由配置
│   └── package.json
│
└── 用户端/          # 顾客小程序（微信小程序）
```

## 功能模块

### 运营端（Web）

| 模块 | 功能 |
|------|------|
| 运营日报 | 数据概览、趋势图、爆款榜、运营建议 |
| 爆款库管理 | 趋势分析、爆款榜、冷门榜预警 |
| 款式管理 | 增删改查、上下架、主推设置 |
| 推荐位管理 | AI智能推荐、手动调整 |
| AI运营助手 | 智能问答、运营建议生成 |

### 用户端（小程序）

- AI试戴：拍照试戴美甲款式
- 款式库：浏览、搜索、筛选款式
- 门店推荐：附近门店、评分、优惠
- 预约到店：一键预约服务

## 技术栈

### 运营端
- Vue 3 + Vite
- Element Plus
- Vue Router 4
- ECharts

### 用户端
- 微信小程序原生
- 云开发

## 快速开始

### 运营端

```bash
cd 运营端
npm install
npm run dev
```

访问 http://localhost:3000

### 用户端

使用微信开发者工具打开 `用户端` 目录

## 项目亮点

1. **美团生态深度整合** - 与到店、团购、评价数据打通
2. **AI试戴** - 多模态模型实现真实试戴效果
3. **数据驱动运营** - 爆款指数、四象限分类法
4. **AI运营助手** - 智能生成运营建议
