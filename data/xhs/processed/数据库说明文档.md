## 数据库结构

本系统包含三个关联数据库：

### 1. 帖子数据库

**文件**: `帖子数据库.csv` / `帖子数据库.json`

每条帖子一行，包含：
- 帖子基本信息（ID、标题、正文、作者等）
- 互动数据（点赞、收藏、评论、分享）
- 标签01矩阵（18个标签列）

**字段说明**:

| 数据库字段 | 原始字段 | 说明 |
|------------|----------|------|
| 帖子ID | note_id | 小红书帖子唯一标识，用于关联图片和评论 |
| 标题 | title | 帖子标题 |
| 正文 | desc | 帖子正文（截取前200字） |
| 作者 | nickname | 发布者昵称 |
| 点赞数 | liked_count | 点赞数量（自动解析"10万+"、"5万"等格式） |
| 收藏数 | collected_count | 收藏数量 |
| 评论数 | comment_count | 帖子显示的评论数 |
| 实际评论数 | - | 实际爬取到的评论条数（可能与显示数不同） |
| 分享数 | share_count | 分享数量 |
| 图片数量 | - | 该帖子下载的图片数量 |
| 帖子链接 | note_url | 小红书帖子链接 |

**数量解析规则**:
- `10万+` → 100000
- `5万` → 50000
- `4.6万` → 46000
- `1k` → 1000

### 2. 图片数据库

**文件**: `图片数据库.csv` / `图片数据库.json`

每张图片一行，包含：
- 图片路径（本地存储路径）
- 帖子ID（关联键）
- 标签01矩阵（18个标签列，继承自所属帖子）

**字段说明**:

| 数据库字段 | 说明 |
|------------|------|
| 图片路径 | 图片的本地存储路径，格式：`{note_id}_{hash}.jpg` |
| 帖子ID | 所属帖子ID，用于关联帖子数据库 |

### 3. 评论数据库

**文件**: `评论数据库.csv` / `评论数据库.json`

每条评论一行，包含：
- 评论ID、帖子ID（关联键）
- 评论内容、IP属地、评论时间

**字段说明**:

| 数据库字段 | 原始字段 | 说明 |
|------------|----------|------|
| 评论ID | comment_id | 评论唯一标识 |
| 帖子ID | note_id | 所属帖子ID，用于关联帖子数据库 |
| 评论内容 | content | 评论文本 |
| IP属地 | ip_location | 评论者IP属地 |
| 评论时间 | create_time | 评论时间戳 |

## 数据对应关系

### 帖子 → 图片

通过 `帖子ID` 关联：
```python
import pandas as pd

posts = pd.read_csv('帖子数据库.csv')
images = pd.read_csv('图片数据库.csv')

# 查找帖子ID为 xxx 的所有图片
post_id = '68e8aa600000000003035e44'
post_images = images[images['帖子ID'] == post_id]
```

### 帖子 → 评论

通过 `帖子ID` 关联：
```python
comments = pd.read_csv('评论数据库.csv')

# 查找某帖子的所有评论
post_comments = comments[comments['帖子ID'] == post_id]
```

### 通过标签筛选

```python
# 筛选所有「夏日美甲」+「猫眼美甲」的帖子
filtered = posts[(posts['季节_夏日'] == 1) & (posts['款式_猫眼'] == 1)]
print(filtered[['帖子ID', '标题', '点赞数']])
```
